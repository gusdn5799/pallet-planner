# 혼적 파레트 적재 플래너

품목명과 박스 수량을 넣으면 혼적 파레트의 탑(기둥) 배치를 자동으로 계산하고, 3D와 앞·뒷면 단면도로 보여주는 출고팀용 도구입니다.

- 파레트: 1100×1100, 바닥 2×2(박스 4개), 권장 5층(20박스), 최대 7층(28박스)
- 서버 없이 `index.html` 한 파일로 동작합니다. 입력한 품목·수량은 각자 브라우저에만 저장됩니다.

## 사용법

1. 왼쪽 **적재 리스트**에 품목명과 박스 수량을 입력합니다. 엑셀에서 두 열(품목명, 수량)을 복사해 **엑셀에서 붙여넣기**로 한 번에 넣을 수도 있습니다.
2. **자동 배치** 결과를 3D와 적재 지시서(앞면 ①② / 뒷면 ③④ 단면)로 확인합니다.
3. 현장 상황에 맞게 고치려면 **직접 배치** → 3D 화면의 **이동·교체**를 켭니다.
   - 박스를 끌어 다른 박스 위에 놓으면 교체, 빈 칸(점선)에 놓으면 그 자리로 이동합니다.
   - 놓기 전에 초록 점선(가능)·빨간 점선(불가)으로 위치를 미리 보여줍니다.
4. **전체 지시서 이미지 복사**를 누르면
   - 전체 지시서가 한 장의 이미지로 PC 클립보드에 복사됩니다 (메신저에 바로 붙여넣기).
   - 구글시트 연동이 설정돼 있으면 '파랫트 적재' 시트의 기존 이미지를 지우고, A4 세로 이미지(파레트 4장씩 1쪽)로 새로 등록합니다. 완료되면 시트 열기 / A4 인쇄용 PDF 링크가 뜹니다.

## 자동 배치 규칙 (우선순위 순)

1. 파레트 수 최소. 5층 기준으로 계산하고, 마지막 파레트가 16박스 이하면 1장 줄여 최대 7층까지 쌓습니다.
2. 20박스 이하 품목은 가능한 한 파레트에 몹니다.
3. ①→②→③→④ 순서로 쌓을 때, 한 품목을 시작하면 그 품목을 다 쌓기 전까지 다른 품목을 쌓지 않습니다.
4. 한 면에 들어가는 품목은 앞면(①②) 또는 뒷면(③④) 한쪽에만 둡니다.
5. 면 안에서는 한 탑을 채우고, 잔여는 옆 탑 맨 아래에 깐 뒤 다른 품목을 올립니다 (예: A7+B3).
6. 간지는 최소로, 한 탑 안에서 품목이 바뀌는 곳마다 넣습니다.
7. 층수(박스 수 ÷ 4 올림)는 넘기지 않습니다. 앞뒤 분산을 피할 수 있으면 탑 높이를 탑마다 다르게 합니다.
8. 6~7층 파레트도 같은 규칙을 쓰고, 기준 높이만 6층·7층으로 바뀝니다.

## 구글시트 연동 (처음 한 번)

1. 구글시트를 열고 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본 `Code.gs` 내용을 지우고, 이 레포의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여넣고 저장합니다.
3. 위쪽 함수 선택에서 **setup**을 고르고 **실행**합니다. 권한 요청을 허용하면, 아래 실행 로그에 `비밀키: …`가 나옵니다. 이 키를 복사해 둡니다.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 **웹 앱 URL**(…/exec)을 복사합니다.
5. 플래너의 적재 지시서 아래 **구글시트 연동 설정**에 웹 앱 URL과 비밀키를 넣고 **저장**합니다. (PC마다 한 번)

참고
- 주소와 비밀키는 코드에 들어가지 않고, 입력한 PC의 브라우저에만 저장됩니다. 비밀키가 맞지 않으면 시트는 바뀌지 않습니다.
- `Code.gs`를 고친 뒤에는 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.
- 시트 등록은 GitHub Pages 주소에서만 됩니다. Claude 미리보기 화면에서는 외부 전송이 막혀 클립보드 복사만 됩니다.
- 인쇄는 함께 뜨는 **A4 인쇄용 PDF** 링크를 쓰는 게 가장 정확합니다. 시트에서 직접 인쇄할 때는 용지 A4, 배율 '너비에 맞춤'을 고르세요.
